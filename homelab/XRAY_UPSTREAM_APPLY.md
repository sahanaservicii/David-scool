# Смена Xray-апстрима на роутере

`xray_upstream_apply.py` — локальный помощник (SSH, stdlib). Секреты не печатает.
Без `--apply` только показывает статус.

## Статус

```bash
python3 xray_upstream_apply.py --check
```

Показывает: последние строки health-check, количество строк nft-таблицы
`inet xrayredir`, код ответа YouTube через локальный SOCKS `10808`, число
тестовых процессов Xray.

## Применение готового конфига

1. Положите **полный рабочий** `config.json` на роутер, например:

```bash
scp my-config.json root@sahanovschi.v6.rocks:/root/new-xray-config.json
```

2. Примените:

```bash
python3 xray_upstream_apply.py --apply /root/new-xray-config.json
```

Скрипт: проверит файл, сделает бэкап текущего конфига на роутере
(`/etc/xray/config.json.bak-<время>`), проверит новый через `xray -test`,
скопирует, точечно перезапустит Xray, проверит health-check/nft/YouTube.
При неудаче автоматически вернёт бэкап и перезапустит Xray.

## Важно

- Пользователь должен передать конфиг/ссылку; офлайн workspace не знает рабочего
  apстрима (все 42 старых канала дают `000`).
- Для проверки на ТВ `192.168.0.12` дополнительно нужен доступ к `192.168.0.0/24`.
- Роутер по умолчанию остаётся в fail-open: при мёртвом апстриме nft-правила
  выключены, остальной интернет работает.
