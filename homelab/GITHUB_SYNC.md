# Еженедельный бэкап и синхронизация навыков с GitHub

Локальный stdlib-скрипт: `homelab/github_sync.py` (нужен только `git`, уже настроен SSH-ключ).

## Назначение
- `github_sync.py skills` — копирует **все** локальные навыки из
  `$OPENCODE_CONFIG_HOME/skills` (по умолчанию `~/.config/opencode/skills`) в
  `.config/opencode/skills/` репозитория и публикует изменения.
- `github_sync.py backup` — запускает `homelab.py backup` (без конфига роутера/HA),
  кладёт архив + манифест в `backups/ГГГГ/ММ/` репозитория и публикует.
- `github_sync.py all` — оба шага, ошибки одного не мешают другому.
- `--dry-run` — только проверка доступа и план, без коммита/push и без создания бэкапа.

## Безопасность
- Секреты не читаются. Перед коммитом проверяются имена файлов и признак
  приватного ключа; при подозрении публикация прерывается.
- В бэкап не попадают `~/.config/opencode/secrets/*`, ключи SSH и конфиг роутера
  (флаги `--with-router`/`--with-ha` не используются).
- Архив содержит инвентарь LAN и `scan.json` — поэтому репозиторий должен
  оставаться **приватным**.
- Ретенция в репозитории сейчас не ограничена; при росте архивов добавить
  удаление старых бэкапов (только по явному подтверждению).
