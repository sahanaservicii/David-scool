# Цикл самоулучшения Домового (оффлайн)

Цель: регулярно делать **одно маленькое безопасное улучшение** в локальной среде, проверять его и при успехе сохранять бэкап.

## Область (разрешено)
- `/root/workspace/homelab/` — скрипты, документация, инвентарь/состояние (кроме секретов).
- `/root/workspace/agentos/` — локальные агенты/инструменты/документация (кроме секретов).
- `/root/.config/opencode/skills/` — навыки (создание/улучшение), если это помогает задачам.
- `/root/workspace/reports/` — отчёты.

## Запрещено в автономном цикле
- Роутер/HA/firewall/VLAN/DNS/Wi-Fi/WireGuard: любые изменения конфигурации.
- Устройства LAN: reboot, factory reset, удаление данных/приложений, открытие портов наружу, включение ADB/UPnP/DMZ.
- Установка пакетов из интернета (`apt`, `pip`, `opkg update/install`, загрузки), облачные API.
- Чтение/вывод секретов (`~/.config/opencode/secrets/*`, токены, пароли, ключи).
- Удаление файлов без явной необходимости; `rm -rf` — никогда без подтверждения пользователя.

## Алгоритм одного запуска
1. **Факты:** `python3 /root/workspace/homelab/homelab.py doctor` (и при необходимости `inventory`). Зафиксировать кратко состояние.
2. **Выбор задачи:** взять одну идею из `IDEAS.md` (приоритет: ресурсосбережение, надёжность, документация, помощники/навыки). Не более 1 изменения за запуск.
3. **Реализация:** внести минимальное изменение.
4. **Проверка:** синтаксис/валидность изменённых файлов (`python3 -m py_compile ...`, `python3 -m json.tool ...`, dry-run/selftest при наличии). При ошибке — откатить изменение, записать неуспех, завершить.
5. **Успех:** обновить `CHANGELOG.md` и `state.json` (что сделано, проверка, время), выполнить бэкап улучшений.
6. **Бэкап после успеха:**
   - `python3 /root/workspace/homelab/homelab.py backup` (локальный архив homelab/state + манифест sha256 в `homelab/backups/`).
   - По возможности: `python3 "$OPENCODE_CONFIG_HOME/skills/android-device/android_device.py" file-backup` (ZIP проекта в Downloads телефона).
7. **Уведомление:** кратко сообщить результат через `python3 /root/workspace/homelab/homelab.py notify --message "..."` (если мост доступен).

## Ресурсные ограничения
- Не запускать тяжёлые параллельные задачи; избегать частых полных `scan` без необходимости (переиспользовать `state/scan.json`, если он свежий).
- При высокой нагрузке/мало памяти — пропустить улучшение, только записать статус и выйти.
- Интервал по умолчанию: каждые 4 часа (расписание OpenChamber), а не «каждую минуту».

## Откат
- Изменения точечные и журналируются в `CHANGELOG.md`; откат — вернуть предыдущую версию файла по журналу/бэкапу из `homelab/backups/`.
