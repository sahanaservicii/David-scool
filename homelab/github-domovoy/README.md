# Domovoy — навыки и еженедельные бэкапы

Приватный репозиторий. Синхронизация выполняется скриптом `homelab/github_sync.py` еженедельно.

- `.config/opencode/skills/` — все локальные навыки Домового.
- `backups/` — локальные бэкапы homelab (инвентарь, scan.json).

Секреты, ключи и токены сюда не попадают.
