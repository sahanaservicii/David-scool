# DIY NFC-дубликатор на ESP32 + PN532 (MIFARE Classic, 7-byte UID)

> ВАЖНО: этот файл — базовая справка. Полный комплект «под ключ»:
> `BUILD.md` (пошаговая сборка и команды), `SCHEMATIC.md` (распиновка),
> `ALL_IN_ONE.md` (BOM и архитектура), `include/config.h` и `src/main.cpp`
> (прошивка SCAN / DUMP / WRITE / EMULATE).

## Что это и чего НЕ делает
- Умеет: **считать UID** карты 13.56 МГц (MIFARE Classic, 7 байт, CL1+CL2), сохранять его во внутренней памяти ESP32 (NVS) и **подставлять этот UID** как карта-эмулятор через PN532 в режиме target.
- Не умеет: эмулировать зашифрованные секторы MIFARE Classic, подбирать ключи, взламывать СКУД. Если турникет проверяет не только UID, эмуляция не сработает.
- Это не полный аналог Flipper Zero: нет 125 кГц, sub-GHz, экрана и готовых дампов. Имейте в виду при сравнении цены и времени.

Ограничение порта: в офлайн-среде нельзя установить toolchain, прошить и проверить устройство у турникета. Здесь только исходники и инструкции.

## Список компонентов (BOM)
| Компонент | Кол-во | Примечание |
|---|---|---|
| ESP32 DevKit (WROOM-32, 30 pin) | 1 | Любая плата с 18/19/23/5 |
| Модуль PN532 (V3 / Elechouse) | 1 | Должен поддерживать режим SPI и target-режим |
| Тактильная кнопка | 1 | Переключение режимов; можно использовать внешнюю на GPIO4 |
| Светодиод + 330 Ом | 1 | Не обязательно — есть встроенный на GPIO2 |
| Батарея 18650 + TP4056 | 1 к-т | Не обязательно; можно питать от USB |
| Макетная плата + перемычки | 1 к-т | — |
| USB-кабель | 1 | Для прошивки |

Питание: PN532 при излучении потребляет до ~150 мА. Если ваш модуль рассчитан на 5 В (на плате есть регулятор) — питайте его от 5 В и через преобразователь уровней; если только 3.3 В — от 3.3 В ESP32, желательно с внешним конденсатором 100 мкФ по питанию.

## Подключение (SPI, пины по умолчанию в скетче)
| PN532 | ESP32 |
|---|---|
| SCK | GPIO18 |
| MISO | GPIO19 |
| MOSI | GPIO23 |
| CS / SS | GPIO5 |
| VCC | 3.3 В (или 5 В — см. маркировку модуля) |
| GND | GND |

- На модуле PN532 выставьте **DIP-переключатели в режим SPI** (позиции смотрите по маркировке на своей плате — у клонов они отличаются).
- Кнопка: одна ножка на GPIO4, другая на GND (в скетче `INPUT_PULLUP`).
- Встроенный светодиод GPIO2 мигает в режиме чтения и горит в режиме эмуляции.

## Сборка и прошивка
**Вариант A — PlatformIO (рекомендуется):**
1. Установить VS Code + расширение PlatformIO на ПК.
2. Открыть папку `esp32_nfc_emulator`, дождаться установки библиотеки `Adafruit PN532`.
3. Подключить ESP32 по USB, выполнить `pio run -t upload`, затем `pio device monitor`.

**Вариант B — Arduino IDE:**
1. Установить Arduino IDE, в Менеджере плат — `esp32` (Expressif).
2. В Менеджере библиотек — `Adafruit PN532`.
3. Открыть `src/main.cpp`, выбрать плату `ESP32 Dev Module`, порт, загрузить. Монитор порта на 115200.

## Использование
1. После прошивки открыть монитор порта (115200). По умолчанию режим **READ**.
2. Приложить пропуск к PN532. Если UID 7 байт — он сохранится в NVS и будет выведен в шестнадцатеричном виде. Сверьте с `../homelab/state/cards/kindergarten.uid.txt`.
3. Нажать кнопку — режим **EMULATE**. Поднести устройство к считывателю.
4. Нажать кнопку ещё раз — возврат в READ.

## Возможная несовместимость библиотеки
В разных версиях `Adafruit_PN532` отличается сигнатура `tgInitAsTarget()`:
- новая: `tgInitAsTarget(SENS_RES, SEL_RES, NFCID, NFCIDLength, timeout)`;
- старая: только `tgInitAsTarget(timeout)` (UID задать нельзя).

Если компиляция падает на этом вызове — обновите библиотеку до 1.2.3+ или откройте `Adafruit_PN532.h` и вызовите доступный вариант с параметрами `nfcid`/`nfcid_len`. В коде это место помечено комментарием `TARGET_API`.

Константы для MIFARE Classic 1K 7B: `SENS_RES = 0x44`, `SEL_RES = 0x08`. Для 4K SAK обычно другой — уточните по показаниям приложения на телефоне.

## Безопасность
- Только свой пропуск/выданный ребёнку, с разрешения сада. Не подбирать ключи MIFARE и не обходить СКУД.
- UID уже был опубликован в переписке — не распространять его дополнительно.
- Не включать эмуляцию в чужих системах и не подключать устройство к WAN.
- Для срочного результата сегодня по-прежнему надёжнее официальный дубликат в саду.
