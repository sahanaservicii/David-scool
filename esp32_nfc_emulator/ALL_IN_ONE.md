# DIY «всё в одном» на ESP32 — BOM, архитектура, рекомендация

Документ подготовлен для офлайн-среды: цен и магазинов здесь нет, только состав, архитектура и ограничения. Ничего не покупается и не прошивается из этой среды.

## 1. Короткая рекомендация
- **Для пропуска детского сада:** уже созданного `esp32_nfc_emulator` (ESP32 + PN532) достаточно для опыта с UID. Для результата «сегодня» надёжнее официальный дубликат в саду.
- **Для профессионального универсального инструмента:** готовый **Flipper Zero** даёт настроенные RF-тракты, корпус, прошивку и экосистему «из коробки». Полный DIY-клон на ESP32 обойдётся не дешевле по времени и почти наверняка будет уступать по LF- и sub-GHz-части.
- **Если всё же собирать:** практичный компромисс — ESP32 + PN532 + CC1101 + OLED + microSD + батарея (≈«80% Flipper»). LF 125 кГц добавлять отдельно и только при реальной необходимости.
- **Специфически для MIFARE Classic:** **Chameleon Ultra** надёжнее именно как эмулятор СКУД, чем универсальный DIY.

## 2. BOM по подсистемам

| Подсистема | Компонент | Назначение | Примечание |
|---|---|---|---|
| MCU | ESP32-WROOM-32 (есть) или ESP32-S3 | Хост, UI, storage | S3 лучше: больше GPIO и native USB |
| NFC HF 13.56 | PN532 (есть) или ST25R3916B | Чтение/запись/эмуляция | PN532 — проще и дешевле; ST25R3916B — ближе к Flipper по возможностям эмуляции |
| NFC HF (альтернатива) | MFRC522 | Только чтение/запись | Эмуляцию не даёт, для нашего проекта не подходит |
| RFID LF 125 кГц | EM4095 / TMS3705 + катушка + конденсаторы | Чтение и эмуляция EM4100/HID | Самая сложная часть: нужно согласовывать антенну |
| LF (reader-only) | RDM6300 | Только чтение | Эмулировать не умеет |
| Sub-GHz | CC1101 (SPI) | Приём/передача 315/433/868 МГц | Только свои устройства и разрешённые диапазоны |
| ИК | TSOP38238 + ИК-светодиод + резисторы | Приём/передача ИК-пультов | Дёшево и просто |
| Дисплей | OLED SSD1306 0.96" I2C или TFT ST7789 SPI | Меню, статус | OLED проще по подключению |
| Ввод | 5-позиционный джойстик / 4–5 кнопок + энкодер | Навигация по меню | На GPIO с `INPUT_PULLUP` |
| Хранилище | microSD-модуль (SPI) | Дампы карт, *.sub, *.ir | Общий SPI-бор, отдельный CS |
| Питание | LiPo/18650 + TP4056 + step-up 5 В + выключатель | Автономность | PN532 при излучении до ~150 мА |
| Мониторинг батареи | Делитель на 2 резистора → ADC | Индикатор заряда | — |
| Уровни/защита | TXS0108E / 74LVC1T45, ESD-диоды | Согласование 5 В/3.3 В | Нужны не для всех модулей |
| Корпус | 3D-печать или бокс, holder для батареи | Механика, антенны | Антенны LF/sub-GHz нельзя прятать в металл |
| Прочее | Макетная плата, перемычки, USB-кабель, кнопка, светодиод | Сборка | — |

## 3. Архитектура

```
                 +-------------------+
                 |   ESP32 / S3      |
                 |  UI + FS + tasks   |
                 +--+--+--+--+--+----+
                    |  |  |  |  |
        SPI (общая шина, разные CS)
        +-----------+  |  |  +----------------+
        |           |  |  |                  |
    PN532/       CC1101 |           microSD
    ST25R3916B       |  |
                     |  +-- ИК (GPIO: RX/TX)
                     +----- OLED (I2C)
                     +----- Джойстик/кнопки (GPIO)
                     +----- АКБ (ADC)

Дополнительно при необходимости:
    EM4095 + катушка 125 кГц -> SPI/UART + аналоговый тракт
```

**Шины**
- SPI: PN532, CC1101, microSD — разные линии CS; тактовая частота ниже максимальной, чтобы не ловить помехи от PN532.
- I2C: OLED и датчики.
- GPIO: кнопки, ИК, светодиод, питание (PN532 EN), ADC батареи.

**Задачи (RTOS)**
1. `nfc_task` — чтение/эмуляция, сохранение UID/дампов.
2. `subghz_task` — приём/передача через CC1101.
3. `ir_task` — ИК-приём/передача.
4. `lf_task` — 125 кГц (если установлен модуль).
5. `ui_task` — меню на OLED, обработка кнопок.
6. `storage_task` — запись/чтение файлов на SD.

**Форматы файлов (совместимость с экосистемой Flipper)**
- `.nfc` — дамп NFC; UID-только файл — упрощённый вариант.
- `.rfid` — LF-карта.
- `.sub` — sub-GHz сигнал.
- `.ir` — ИК-пульт.

## 4. Что реально сложно
- **LF 125 кГц:** антенна и согласование. Без нормальной катушки и конденсаторов эмуляция не заработает — это не «воткнул модуль и готово».
- **Полная эмуляция MIFARE Classic:** требует Crypto1 и ключей секторов; в базовом проекте реализована только подстановка UID. Подбор ключей не планируется и не разрешён.
- **Sub-GHz:**_leгальность — только свои пульты/устройства и разрешённые частоты; мощность и duty cycle должны соответствовать правилам.
- **Питание:** PN532 и CC1101 одновременно могут просесть на одном LDO; нужен запас по току и сглаживание.
- **Корпус и антенны:** металлический корпус убивает LF и sub-GHz приём.

## 5. Что докупить для «80% варианта» (рекомендуемый минимум)
1. CC1101 — sub-GHz.
2. OLED SSD1306 0.96" — интерфейс.
3. microSD-модуль — хранилище дампов.
4. Джойстик/кнопки — навигация.
5. Батарея + TP4056 + step-up + выключатель — автономность.
6. Дополнительные перемычки и конденсатор 100 мкФ по питанию PN532.

LF-модуль (EM4095 + катушка) — **только если** появятся задачи с 125 кГц. Для текущего пропуска он не нужен: карта уже определена как 13.56 МГц MIFARE Classic.

## 6. Сравнение

| Критерий | DIY на ESP32 | Flipper Zero | Chameleon Ultra |
|---|---|---|---|
| HF NFC 13.56 | Есть (PN532/ST25R3916) | Есть, хорошо интегрирован | Есть, лучший для СКУД |
| LF 125 кГц | Сложно (антенна) | Есть из коробки | Зависит от ревизии |
| Sub-GHz | Нужен CC1101 | Есть из коробки | Нет |
| ИК | Нужны компоненты | Есть из коробки | Нет |
| Экран/меню | Нужно собирать | Есть | Нет/минимально |
| Время до результата | Дни-недели | Сразу | Сразу |
| Стоимость усилий | Высокая | Низкая | Низкая |
| Гибкость | Максимальная | Ограничена прошивкой | Средняя |

**Вывод:** для «профессионального инструмента сегодня» берите готовое. DIY имеет смысл как долгосрочный проект и учебный стенд. Для именно этого пропуска минимальная рабочая связка — уже существующий ESP32 + PN532 плюс официальный дубликат в саду.

## 7. Безопасность
- Только свои карты/пульты, с разрешения владельца системы. Никаких чужих СКУД и подбора ключей.
- Не открывать наружу порты, не подключать устройство к WAN.
- UID сохранён в `../homelab/state/cards/kindergarten.uid.txt` и уже был в переписке — не распространять его дополнительно.
- Проект в этой среде не прошивается и не проверяется у турникета — успех на этом шаге = BOM + архитектура + рекомендация.
