## 1. Железо
Минимум (уже есть): ESP32 DevKit + модуль PN532.
Дополнительно для записи копии: **пустая карта/брелок с меняемым UID** (так называемая magic-карта, MIFARE Classic 1K, Gen1a — direct write block 0). Обычная карта block 0 не перезаписывает.

Без пустой карты режим WRITE не имеет смысла — останутся SCAN и EMULATE.

## 2. Сборка
1. Собрать по `SCHEMATIC.md`: SPI (SCK=18, MISO=19, MOSI=23, CS=5), VCC/GND, кнопка GPIO4, конденсатор 100 мкФ.
2. Выставить DIP-переключатели PN532 в режим SPI согласно маркировке вашего модуля.
3. Подключить ESP32 по USB.

## 3. Прошивка
**PlatformIO:** открыть папку проекта → дождаться установки `Adafruit PN532` → `pio run -t upload` → `pio device monitor` (115200).

**Arduino IDE:** установить пакет плат `esp32` и библиотеку `Adafruit PN532` (1.2.3+), открыть `src/main.cpp`, выбрать `ESP32 Dev Module`, загрузить, открыть монитор на 115200.

## 4. Работа с устройством
Команды в мониторе порта (без регистра, Enter):

| Команда | Что делает |
|---|---|
| `S` | SCAN — считать UID (ожидается 7 байт), сохранить |
| `D` | DUMP — прочитать доступные секторы штатными ключами |
| `W` | WRITE — записать копию на пустую magic-карту (нужно набрать `YES`) |
| `E` | EMULATE — подставить сохранённый UID как карту |
| `P` | PRINT — показать сохранённое состояние |
| `H` | HELP — справка |

Порядок для дубликата:
1. `S` → приложить **оригинальный** пропуск → сверить UID с `../homelab/state/cards/kindergarten.uid.txt`.
2. `D` → приложить оригинал → посмотреть, сколько секторов прочитано. Если секторы защищены своими ключами — они будут пропущены, подбор ключей не производится.
3. `W` → подтвердить `YES` → приложить **пустую** magic-карту. Программа запишет блок 0 с UID и все известные блоки. Затем снова `S` и сверить UID копии.
4. `E` → поднести устройство к турникету. Кнопка GPIO4 или `q` — выход.

## 5. Проверка и честные ожидания
- Успех на этом шаге: файлы готовы, инструкция понятна, UID-/дамп-логика реализована.
- **Не обещается** рабочий проход у турникета: это можно проверить только физически. Если считыватель проверяет зашифрованные секторы, одного UID мало.
- Прошивка компилируется на вашем ПК; в этой офлайн-среде нет toolchain и железа, поэтому здесь она не проверялась компилятором.
- Если компилятор ругается на `tgInitAsTarget(SENS_RES, SAK, UID, LEN, timeout)` — обновить Adafruit PN532 до 1.2.3+ или вызвать доступную перегрузку с `nfcid`/`nfcid_len` (помечено `TARGET_API` в старой версии README).

## 6. Безопасность
- Только свой пропуск ребёнка, с разрешения сада. Не трогать чужие карты и СКУД, не подбирать ключи.
- `WRITE` требует явного `YES` и работает только с заранее подготовленной пустой картой.
- UID уже был в переписке — не распространять его дополнительно.
- Не подключать устройство к WAN и не открывать порты наружу.
- Для срочного результата сегодня по-прежнему надёжнее официальный дубликат в саду.
