# Схема подключения ESP32 + PN532 (дубликатор)

## Подключение

| PN532 | ESP32 | Примечание |
|---|---|---|
| SCK | GPIO18 | общая SPI-шина |
| MISO | GPIO19 | |
| MOSI | GPIO23 | |
| CS / SS | GPIO5 | отдельный CS |
| VCC | 3.3 В | либо 5 В, если на модуле есть регулятор и level-shifter |
| GND | GND | общая земля обязательна |

Дополнительно:
- Кнопка: GPIO4 ↔ GND, в коде `INPUT_PULLUP` (выход из эмуляции).
- Светодиод: встроенный на GPIO2 (горит в эмуляции).
- Конденсатор 100 мкФ параллельно питанию PN532 (он потребляет до ~150 мА).
- Дополнительные SPI-устройства (CC1101, microSD) — на той же шине, но со своими CS.

## Текстовый вариант схемы

```
   +3.3V ──┬────────────── ESP32 3V3
           │
         100мкФ
           │
   PN532 VCC

   PN532 SCK  ── GPIO18
   PN532 MISO ── GPIO19
   PN532 MOSI ── GPIO23
   PN532 CS   ── GPIO5
   PN532 GND  ── GND

   Кнопка GPIO4 ── GND
   LED (встроенный) GPIO2
```

## DIP-переключатели PN532
Режим **SPI** выставляется по маркировке на вашей плате — у разных ревизий Elechouse/клонов позиции отличаются. Если модуль в HSU/I2C, SPI не заработает.

## Питание
- Если модуль PN532 только на 3.3 В — питать от 3.3 В ESP32, но следить за током.
- Если на плате есть 5V->3.3V регулятор и преобразователи уровней — можно 5 В от внешнего step-up.
- Не подавать 5 В на GPIO ESP32 напрямую.

## Ограничение
Схема проверена только на соответствие распиновке кода; физически здесь её нельзя собрать и проверить.
