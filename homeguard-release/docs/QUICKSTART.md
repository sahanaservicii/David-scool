# HomeGuard — быстрый старт: установил и работает

Офлайн-комплект: консоль на телефоне родителя (сервер `http://<LAN-IP-родителя>:8787`),
агент на телефоне ребёнка (Device Owner). Connecting через LAN и WireGuard.
**Никакого GitHub, облака, FCM и подписок.**

Готовые APK: `dist/console-1.4.1.apk`, `dist/agent-1.3.1.apk`. Сначала консоль, потом агент.

---

## 0. Что понадобится

- Два телефона в одной домашней сети `192.168.0.0/24`: родитель (консоль) и ребёнок (агент).
- Компьютер с `adb` и кабелем — только для первого запуска агента и Device Owner.
- WireGuard-клиент на обоих телефонах и локальный WG-конфиг/QR (см. шаг 2).
- APK из `dist/`; контрольные суммы — `dist/SHA256SUMS`.

Проверьте суммы перед установкой:

```bash
cd dist && sha256sum -c SHA256SUMS
```

## 1. Консоль на телефоне родителя

1. Установите `dist/console-1.4.1.apk`, откройте, разрешите уведомления.
2. На главном экране найдите строку `Сервер: http://…:8787` — **запишите этот LAN-IP**
   (это и есть `<LAN-IP-родителя>`; не используйте примеры из документации).
3. Нажмите «Проверить сервер» → должно быть «сервер работает».
4. В батарее для HomeGuard включите «Без ограничений»: телефон родителя и есть сервер.
   Не закрывайте приложение на время настройки.

Если «Проверить сервер» красное: проверьте, что телефоны в одной сети, порт 8787
не занят, и что консоль не убита системой.

## 2. WireGuard (split-tunnel, только домашняя подсеть)

Консоль в туннеле: `192.168.9.2:8787`. Ребёнок: `192.168.9.3/32`.
Разрешённый трафик: **только `192.168.9.0/24`**, не весь интернет.

1. Установите WireGuard-клиент на оба телефона (из F-Droid/Play — локально скачанный APK,
   если интернет недоступен).
2. Импортируйте локальный конфиг/QR: у ребёнка `Address = 192.168.9.3/32`,
   `AllowedIPs = 192.168.9.0/24`, `PersistentKeepalive = 25`, Endpoint — ваш WG-сервер.
3. Поднимите туннель на обоих телефонах. В клиенте должен быть последний handshake
   и nonnegative «последний обмен».

⚠️ QR/confix содержит **приватный ключ**. Не показывайте его посторонним, не делайте
скриншоты и не публикуйте. Не включайте full-tunnel `0.0.0.0/0`.

**Важно про проверку с компьютера:** хост в LAN может **не видеть**
`192.168.9.2` — это нормально, если WG поднят только на телефонах. Проверять доступ
нужно **с телефона ребёнка**, а не с ПК.

## 3. Агент на телефоне ребёнка (Device Owner)

Device Owner можно поставить **только на свежесброшенном телефоне**, до добавления
аккаунтов и второго пользователя. Сброс — разрушительное действие; выполняйте его
только если вы согласны стереть данные телефона.

```bash
adb devices
adb install -r dist/agent-1.3.1.apk
adb shell dpm set-device-owner ru.homeguard.agent/.GuardReceiver
```

Ожидаемый вывод: `Success: Device owner set to package ComponentInfo{...}`.
Если `dpm` ругается на существующие аккаунты — нужен повторный сброс и установка
до добавления аккаунта. Подробности: [PROVISIONING.md](PROVISIONING.md).

## 4. Привязка через QR

1. В консоли: «Добавить ребёнка» → имя → откроется экран с **крупным QR-кодом**
   и строкой `hg1:…` под ним.
2. На телефоне ребёнка откройте агент → «Сканировать QR» → разрешите камеру →
   наведите на QR, **держите экран ровно** → подтвердите адрес консоли →
   «Сохранить привязку».
3. Запасной путь, если камера не прочитала: введите ту же строку `hg1:…`
   в поле «Код привязки» вручную. Строку можно скопировать из экрана консоли.

Совместимость: сначала обновить консоль, потом агента. Старая пара 1.4.0/1.3.0
работает с новыми APK, но смешивать версии не рекомендуется.

## 5. Чек-лист «всё работает»

- [ ] Консоль: «Сервер: http://…:8787» и «сервер работает».
- [ ] WG на обоих телефонах: туннель поднят, есть handshake.
- [ ] Агент: в разделе «Настройка» статус «Права владельца: Готово».
- [ ] Привязка сохранена: агент видит имя ребёнка, консоль показывает устройство онлайн.
- [ ] Агент получил политику (пришло последнее состояние).
- [ ] Камера/ввод: привязка подтверждена без ошибок подписи.

## 6. Smoke-тесты (после привязки)

1. Политика: поменяйте лимит/настройку в консоли — агент должен применить её в течение
   ближайшего опроса.
2. Блокировка: запретите приложение → убедитесь, что оно не открывается; снимите запрет.
3. Запрет установки: попробуйте установить APK — должно быть заблокировано.
4. Тихий час: включите на 5 минут — ограничения 적용ятся.
5. SOS: отправьте тестовое сообщение — оно появится в консоли.
6. Отчёт: сформируйте отчёт за день.
7. Бэкап: сделайте `.hgbak` и проверьте восстановление.

## 7. Если не работает

| Симптом | Что проверить |
|---|---|
| «не подключён VPN» | Это сообщение **WireGuard-клиента**, не консоли. Поднимите туннель, проверьте handshake на обоих телефонах и `AllowedIPs = 192.168.9.0/24`. |
| Консоль не видна агенту | Адрес из экрана консоли, порт 8787, батарея «Без ограничений», туннель 192.168.9.2. С ПК туннель может быть не виден — проверяйте с телефона. |
| Ошибка подписи / «неподписанный ответ» | Обновите консоль и агента с одного выпуска (1.4.1 / 1.3.1). Не смешивайте старые APK. |
| QR не сканируется | Держите экран ровно, не меняйте масштаб; используйте ручной ввод `hg1:…`. |
| `dpm set-device-owner` не проходит | Телефон должен быть сброшен, без аккаунтов и второго пользователя. |

## 8. Чего делать нельзя

- Не открывайте порты наружу, UPnP, DMZ, ADB 5555.
- Не включайте full-tunnel WireGuard — только `192.168.9.0/24`.
- Не публикуйте QR с приватным ключом и скриншоты экрана привязки.
- Не меняйте роутер/firewall без отдельного решения и бэкапа.
