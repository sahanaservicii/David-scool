# Ввод в эксплуатацию

## 0. Что понадобится

* Ваш телефон с консолью, телефон ребёнка (Android 13–15), Wi-Fi `192.168.1.0/24`.
* `adb` на любом ПК (из Android SDK, каталог `platform-tools`).
* Один раз — сброс телефона ребёнка к заводским настройкам: без этого Device
  Owner не выдаётся (Android не разрешает назначить владельца на «живое»
  устройство с аккаунтами). Данные сохраните заранее.

## 1. Консоль

1. Установите `dist/console-1.4.2.apk`, откройте, разрешите уведомления.
2. Убедитесь, что на экране: `Сервер: http://<ip>:8787`, состояние «сервер
   работает».
3. «Проверить сервер» → «сервер отвечает: OK».
4. «Добавить ребёнка» → имя → скопируйте строку привязки.

Держите консоль включённой: это и есть сервер. Если телефон уйдёт в глубокий
сон, система может остановить службу — включите для HomeGuard
«Не ограничивать»/«Без ограничений» в настройках батареи.

## 2. Телефон ребёнка — вариант A (ADB, рекомендуется)

```bash
adb devices
adb install -r dist/agent-1.4.0.apk
# до добавления аккаунтов и без второго пользователя:
adb shell dpm set-device-owner ru.homeguard.agent/.GuardReceiver
```

Ожидаемый вывод: `Success: Device owner set to package ComponentInfo{...}`.

Если `dpm` пишет `Not allowed to set the device owner because there are already
some accounts on the device` — сделайте сброс и не добавляйте аккаунт до
команды. После назначения владельца аккаунт добавить можно.

Затем на телефоне откройте агент. Сверху — индикатор «Готовность N из 9»
и чек-лист «Настройка»: каждый пункт со статусом «Нужно» открывает нужный
системный экран. Пройдите сверху вниз:

1. **Права владельца** — уже выданы командой `dpm`, пункт сразу «Готово».
   Если `dpm` не применялся, пункт откроет экран администраторов устройства
   (полный контроль при этом не включится — вернитесь к ADB).
2. **Привязка к консоли** — в консоли родителя откройте ребёнка → «Привязать»:
   появится крупный QR-код. В агенте нажмите «Сканировать QR», наведите камеру
   на код (держите ровно), подтвердите адрес и «Привязать». Если камера не
   сработала — введите ту же строку в поле «Код привязки» вручную.
3. **Уведомления** — разрешить.
4. **Геолокация** — разрешить (для геозон; владельцу устройства выдаётся сразу).
5. **Статистика использования** — HomeGuard → разрешить.
6. **Специальные возможности** — HomeGuard → включить (блокировка приложений).
7. **Поверх других приложений** — разрешить (экран блокировки).
8. **Батарея без ограничений** — разрешить.
9. **Отладка по USB** — выключить после настройки.

Защита стартует сама при открытии агента: отдельной кнопки «Запустить» больше
нет. Когда все девять пунктов «Готово», шапка показывает «Защита включена».
Кнопка **SOS** на главном экране отправляет сигнал и координаты в консоль.

Проверка: в консоли устройство станет «онлайн» в течение 2 минут, придут
батарея, модель и экранное время.

## 3. Вариант B (QR-провижининг, как у корпоративных устройств)

Нужен, если удобнее настроить телефон сразу после сброса, без ADB.

```bash
# на машине с APK, в той же LAN:
python3 tools/provision.py --apk dist/agent-1.4.0.apk \
    --console 192.168.1.10:8787 --device-id kid-ab12 \
    --code ABCD-EFGH-JKLM-NPQR --json --serve
```

Скрипт печатает extras и раздаёт APK по `http://<ip>:8000/agent-1.4.0.apk`.
Полученную строку закодируйте любым офлайн-QR (`qrencode`, приложение на
телефоне) и на экране приветствия свежесброшенного телефона нажмите 6 раз в
одно и то же место → сканер QR.

Ограничение: во время первоначальной настройки телефон должен видеть вашу
машину по сети (подключите Wi-Fi в мастере). Если сеть недоступна — используйте
вариант A.

## 4. Сеть: статический адрес и WireGuard

Агент помнит адрес консоли из кода привязки, поэтому адрес не должен меняться.

* **DHCP-reservation** для телефона-консоли в LuCI: Network → DHCP/DNS →
  Static Leases (`MAC` → `192.168.1.10`).
* **WireGuard на OpenWrt**: Network → Interfaces → Add → WireGuard, затем
  firewall-зона `wg` → `input ACCEPT`, `forward` только в `lan`, и правило:
  разрешить `8787/tcp` из `wg` в `lan`, больше ничего наружу не открывать.
  Проброс портов (DNAT) не нужен и не рекомендуется.
* Телефон ребёнка вне дома: клиент WireGuard на самом телефоне (или на роутере
  с маршрутом по умолчанию через туннель), адрес консоли остаётся тем же.

Если SSH на роутере выключен (`192.168.1.1:22` закрыт), включите его в LuCI:
System → Administration → SSH Access → *Enable*, либо через последовательный
порт. Без SSH WireGuard я настроить не могу.

## 5. Что проверить после установки

| Проверка | Откуда |
|---|---|
| `Device Owner: ДА` | экран агента |
| Устройство «онлайн», свежая батарея | консоль → устройство |
| Блокировка: команда «Заблокировать экран» → телефон гаснет, появляется «Заблокировано родителем» | консоль |
| «Разблокировать» возвращает рабочий стол | консоль |
| Установка APK запрещена, если политика «Установка новых приложений» выключена | телефон ребёнка |
| Тихий час: поставьте окно на 2 минуты вперёд | консоль → политика |
| SOS: кнопка на главном экране агента → событие в консоли | агент |
| Готовность в агенте: 9 из 9 | агент |
| Отчёт: экранное время появилось | консоль → отчёты |

## 6. Откат

* Снять Device Owner: `adb shell dpm remove-active-admin
  ru.homeguard.agent/.GuardReceiver` — работает только если у админа нет
  активных ограничений; иначе сначала выключите все запреты в политике, затем
  `adb shell dpm remove-active-admin`. Крайний случай — сброс устройства.
* Полное удаление: удалить оба приложения; данные консоли (политики, история)
  хранятся только на вашем телефоне.
