# Вклад в проект

Код — Java 17 без AndroidX, Compose и сторонних JAR. Среда сборки офлайн:
все зависимости — Android SDK и Gradle, уже установленные на машине.

## Правила

1. Не добавляйте зависимости без крайней нужды: маленький APK и минимальная
   поверхность атаки важнее удобства.
2. Любое изменение протокола вносите **зеркально** в `Protocol.java` агента
   и консоли и добавляйте проверку в `tools/tests/TestRunner.java`.
3. Один шаг — одна проверка: после изменения `sh tools/test.sh`, затем сборка.
4. Секреты, ключи, реальные IP и домашние домены в репозиторий не попадают.
   Для локальной сборки используйте `local.properties` и
   `keystore.properties` по примеру `*.example` — они в `.gitignore`.
5. Версии/modules поднимаются независимо в `agent/build.gradle` и
   `console/build.gradle`; если меняется протокол — обновляйте обе.
6. Разрушительные действия (wipe, сброс, удаление правил) — только по
   явному запросу пользователя и с подтверждением.

## Проверки перед PR

```bash
sh tools/test.sh
gradle lintDebug assembleDebug
```

Ожидаемо: 34/34 тестов протокола, без ошибок lint.
