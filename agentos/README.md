# agentos — 113 офлайн мини-агентов для дома и сети

Детерминированная мультиагентная система на чистом Python stdlib. Работает
**без интернета, без облаков, без pip-пакетов и без GPU**. Все действия —
в локальной сети `192.168.1.0/24` и локальных файлах.

```
113 агентов · 11 категорий · 0 зависимостей · 0 сетевых вызовов наружу
```

## Честно о «ИИ»

В этой системе **нет языковой модели**: на хосте нет ни GPU, ни свободной RAM
под 7B-модель, ни интернета, чтобы её скачать (проверено: egress заблокирован).
Поэтому «интеллект» здесь — не генерация текста, а:

1. **маршрутизация по смыслу** (стемминг + взвешенный TF по id, имени,
   ключевым словам и описанию агента) — 37/37 тестовых запросов;
2. **113 детерминированных навыков** с реальными инструментами;
3. **самопроверка** каждого агента и измеримая метрика качества.

Гнездо под локальную LLM готово и включится само, если появится сервер:
`llama-server -m model.gguf --port 8080` или `ollama serve` (порт 11434).
Тогда `ai.ask`, `ai.rewrite`, `ai.status` начинают отвечать свободным текстом,
а остальные 97 агентов работают как раньше — им LLM не нужна.

## Быстрый старт

```bash
cd /root/workspace/agentos

./bin/agentos selftest          # проверка всех 113 агентов + маршрутизации
./bin/agentos doctor            # состояние системы
./bin/agentos serve --open      # браузерный интерфейс на 127.0.0.1
./bin/agentos "проверь пинг 192.168.1.1" --live
./bin/agentos list              # кто есть
./bin/agentos "план дня"
```

Без обёртки:

```bash
PYTHONPATH=/root/workspace/agentos python3 -m agentos selftest
```

Первый запуск ничего не пишет вне `data/` и `out/`: по умолчанию включён
**dry-run** — агенты показывают, что сделали бы. Реальные действия — с `--live`.

## Переносимый комплект (флешка, другой ПК, телефон)

```bash
python3 tools/build_portable.py        # dist/agentos-portable/ + zip
cd dist/agentos-portable && ./run.sh selftest
```

Для Windows 10 в комплект вложен Python 3.12 (embeddable) — ставить ничего
не нужно, запуск `start.cmd` (браузер) или `start-lan.cmd` (доступ из LAN).
Для Linux/Android нужен только `python3` (3.10+). Данные создаются
в `data/` рядом с комплектом; если каталог только для чтения — в
`~/.local/share/agentos`. Пути в примерах используют алиасы `@app` и
`@homelab`, поэтому папку можно переносить куда угодно.

На Windows 10: распаковать zip и в `cmd` выполнить `run.cmd selftest`
(нужен Python 3.10+, `run.cmd` сам выберет `py -3` или `python`).

На Android: `pkg install python` в Termux (один раз), распаковать zip,
`./run.sh selftest`. Сервер на телефоне слушает `127.0.0.1` — открывать
`http://127.0.0.1:8765` в браузере того же телефона, токен печатается
при старте.

## Как это устроено

```
agentos/
├── agentos/
│   ├── core.py        реестр, роутер, память, исполнение
│   ├── tools.py       песочница ФС, whitelisted shell, LAN-проверки
│   ├── llm.py         опциональный локальный LLM (OpenAI-совместимый)
│   ├── cli.py         ask/run/list/show/selftest/doctor/mem/route/serve/catalog
│   ├── server.py      HTTP API на 127.0.0.1
│   ├── utils.py       форматирование, слаги, параметры, redact
│   └── agents/        сами агенты, 10 модулей
├── bin/agentos        запуск без установки
├── tests/             unittest, stdlib
├── data/              память (SQLite), конфиг, логи, out/
├── out/               результаты работы (отчёты, архивы, манифесты)
└── CATALOG.md         автогенерируемый каталог всех агентов
```

Жизненный цикл запроса:

```
фраза → нормализация (стемминг, RU+EN) → скоринг 113 агентов
      → порог уверенности (3.0) → исполнение в песочнице
      → запись в SQLite (кто, что, сколько мс, результат) → ответ
```

Если уверенность низкая — система не угадывает, а возвращает список похожих
агентов с оценками (никогда не «делает вид», что поняла).

### Windows, cmd и PowerShell

13 агентов категории `windows` дают администрирование без RDP-мышкования:

```bash
./bin/agentos run win.info                      # версия, сборка, память (systeminfo)
./bin/agentos run win.cmd "ipconfig"            # allowlist: ver, whoami, ipconfig,
                                                # tasklist, netstat, route, systeminfo,
                                                # hostname, getmac, driverquery
./bin/agentos run win.ps "Get-Service"          # PowerShell только на чтение
./bin/agentos run win.services                  # список служб
./bin/agentos run win.services "action=restart name=Spooler подтверждаю" --live
./bin/agentos run win.process "top=15"          # топ процессов по памяти
./bin/agentos run win.disk                      # тома, свободное место
./bin/agentos run win.eventlog "n=10 level=error"
./bin/agentos run win.users                     # локальные учётки
./bin/agentos run win.tasks                     # планировщик
./bin/agentos run win.firewall                  # правила брандмауэра (чтение)
./bin/agentos run win.updates                   # Get-HotFix
```

Ограничения (намеренные):

- без `--live` — только dry-run: печатается точная команда, ничего не выполняется;
- `win.cmd` не принимает произвольные аргументы — только фиксированный allowlist;
- `win.ps` — только `Get-*`/`Test-*`, запрещены `;`, конвейеры, `Invoke-Expression`,
  `Start-Process`, `Remove-*`, `Set-*`, запись в файлы;
- старт/стоп/перезапуск службы и kill процесса требуют `подтверждаю` (или
  `confirm=да`) **и** `--live`;
- вне Windows агенты честно отвечают «только в Windows», selftest помечает их `skip`.

## Браузерный интерфейс и HTTP API

```bash
./bin/agentos serve --open            # страница на 127.0.0.1:8765
./bin/agentos serve --host 0.0.0.0    # доступ с телефона/другого ПК в LAN
```

`http://127.0.0.1:8765/?token=…` — мобильная страница: запрос, выбор агента,
подсказки, история (в браузере). Токен печатается при старте, сохраняется в
`data/config.json` и подставляется в ссылку; `/health` открыт, `/agents` и
`/ask` — только с токеном (`Authorization: Bearer …` или `?token=…`).

```bash
curl -s localhost:8765/health
curl -s -H "Authorization: Bearer $TOKEN" -X POST localhost:8765/ask \
     -d '{"query":"покажи arp таблицу"}'
```

По умолчанию bind `127.0.0.1`; `--host 0.0.0.0` — только своя LAN, наружу
порт не пробрасывать. Тело запроса ≤ 64 КиБ. Без `--live` всё в dry-run.

## Безопасность

- **ФС-песочница:** чтение — только `agentos/`, `homelab/`, `/tmp/opencode`;
  запись — только `data/` и `out/`. Выход за пределы (включая symlink и `..`)
  → `ToolError`. Исключение: `sec.logs` читает `/var/log` (только чтение).
- **Shell без shell:** whitelist содержит только не-файловые команды
  (`ping`, `ip`, `ss`, `df`, `uname`, `uptime`, `free`, `ps`, `date`,
  `hostname`, `which`, `getent`). `cat`/`tail`/`tar`/`curl`/`sqlite3` и пр.
  запрещены — работа с файлами идёт только через песочницу.
- **Сеть:** только адреса из `network` в конфиге. Числовые формы IP
  (`2130706433`, `0x7f000001`), имена вне LAN и внешние URL отклоняются;
  DNS-имена проверяются по всем полученным адресам.
- **Секреты:** файл `~/.config/opencode/secrets/homelab.env` не читается
  агентами; `hl.secrets` показывает только имена ключей и права. Вывод
  `fs.read`/`fs.grep` всегда проходит через `redact` (`KEY=value`,
  `"token": "…"`, `HASS_TOKEN=…`). Агенты с паролями/токенами помечены
  `secret=True` — в журнал `data/memory.sqlite` пишется `[скрыто]`.
- **Калькулятор** — разбор AST, а не `eval`: `__import__('os').system(...)`
  отклоняется; степень ограничена 1000, `fact` — 10000 (покрыто тестами).
- **Regex-агенты** отсекают вложенные квантификаторы (`(a+)+`) и шаблоны
  длиннее 300 символов.
- **Опасное — только по явной команде:** `--live` + отдельный агент.
  Никаких reboot/sysupgrade/firewall-изменений в коде нет.

## Добавить своего агента

```python
# agentos/agents/mine.py
from ..core import Context, agent

@agent("my.hello", "Приветствие", "life",
       "Здоровается с указанным именем",
       keywords=("привет", "здравствуй"), examples=("Иван",))
def hello(ctx: Context, text: str):
    return f"Привет, {text.strip() or 'мир'}!"
```

Файл подхватится сам, `selftest` его проверит, `list` покажет.
Правило: имя файла не с `_`, id — `категория.имя`, у агента есть `examples`.

## Ограничения (важно)

- Нет LLM → нет генерации текста и «понимания» сложных формулировок;
  маршрутизация — по словам, а не по смыслу в глубоком смысле.
- В этой среде нет бинарников `ip`, `ping`, `ss`, а `/proc` и `/sys` закрыты.
  Поэтому ARP-агент берёт список устройств из `homelab.py inventory`,
  интерфейсы — из socket (локальный адрес), а остальные агенты честно
  сообщают об отсутствии инструмента. Доступность проверяется по TCP.
- Хост живёт на `10.234.61.136`, а не в `192.168.1.0/24`: сеть из конфига
  физически недоступна. Шлюз `192.168.1.1` не отвечает, ADB выключен —
  агенты показывают это, а не имитируют успех.
- HA отключён (`home_assistant.enabled=false`) — агенты HA не создавались.
