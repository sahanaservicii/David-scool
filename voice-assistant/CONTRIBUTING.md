# Contributing / Доработка

Проект открыт для доработки и улучшений под свои нужды.

## Быстрый старт для разработки
```bash
python3 -m unittest discover -s tests -v
python3 main.py --status
python3 main.py --web --host 127.0.0.1 --port 8766
```

## Как добавить навык
1. Создайте класс в `assistant/skills/<name>_skill.py` (наследник `Skill`).
2. Добавьте intent/паттерны в `assistant/nlu/router.py`.
3. Зарегистрируйте навык в `assistant/core/engine.py`.
4. При необходимости добавьте настройку в `config/config.json`.
5. Добавьте тест в `tests/`.

См. `docs/SKILLS.md` и `docs/ARCHITECTURE.md`.

## Принципы
- **Офлайн-first**, минимум зависимостей (stdlib для ядра).
- **Безопасность по умолчанию**: не выполнять произвольные команды из пользовательского ввода, подтверждать деструктивные действия, не коммитить секреты.
- **Провайдеры заменяемы**: STT/TTS/LLM/Search через абстракции.
- **Тесты** для ключевой логики и регрессий.

## Идеи для улучшений
- Офлайн STT/TTS (sherpa-onnx/Vosk/Piper/Whisper.cpp) с моделями.
- Wake-word + VAD, потоковый диалог.
- Улучшение NLU (слоты, ML/LLM intent extraction), рутины и сценарии.
- Интеграции: календарь, медиа, Home Assistant/MQTT, уведомления.
- Аутентификация и TLS для веб-интерфейса.
- CI, линтеры, дополнительные тесты и метрики качества.
