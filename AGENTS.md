# Инструкции для агентов в /root/workspace

Это домашняя лаборатория. По умолчанию используется агент **Домовой**
(`default_agent: domovoy`), но правила ниже действуют для любого агента.

## Главное

- Всё работает **офлайн**: только локальные сети подтверждённой/активной
  локации (см. `homelab/homelab.json`: `active_location`, `network`,
  `locations.*`), локальные API и установленные инструменты. Никаких облаков,
  подписок, платных сервисов. Перед работой определяй локацию/сеть
  (`doctor`, `inventory`, `homelab.json`) и не смешивай данные разных локаций
  (например, квартира/дача) без явного подтверждения.
- **Каждый запрос пользователя начинай с уточнения:** загрузить навык `clarify`
  и вызвать подагента `clarify`, задать ровно 3 конкретных вопроса (результат,
  границы, контекст/приоритет) через инструмент `question` и дождаться ответов.
  Очевидные задачи — тоже 3 вопроса, но как быстрое подтверждение. До ответов
  ничего не менять.
- Инструменты: `/root/workspace/homelab/homelab.py` (Python stdlib).
  Инструкция — `homelab/README.md`, инвентарь — `homelab/INVENTORY.md`,
  аварийные процедуры — `homelab/RUNBOOK.md`.
- Секреты — только в `~/.config/opencode/secrets/homelab.env`. Не читать без
  нужды, не печатать, не копировать в отчёты и чат.

## Перед изменениями

1. `python3 homelab.py doctor` и/или `inventory`.
2. Бэкап: `python3 homelab.py backup --with-router --with-ha`.
3. Один шаг — одна проверка. Разрушительное (reboot, sysupgrade, firewall,
   удаление данных) — только с явным подтверждением пользователя.

## Делегирование

Главный агент `domovoy` раздаёт задачи подагентам: `network`, `home`,
`android`, `security`, `backup`, `docs`. Независимые части — параллельно,
после подагентов — самостоятельная проверка результата.

## Ограничения

- Не трогать чужие сети и устройства вне подтверждённых своих сетей/локаций.
- Не открывать наружу порты, UPnP, DMZ, ADB 5555.
- Не устанавливать пакеты из интернета: среда офлайн.

## Цикл самоулучшения (Домовой)

Периодический офлайн-цикл: одно маленькое безопасное улучшение за запуск → проверка → журнал → бэкап при успехе.
- Runbook/идеи/журнал/состояние: `/root/workspace/homelab/self_improve/` (`RUNBOOK.md`, `IDEAS.md`, `CHANGELOG.md`, `state.json`, `cycle.py`).
- Навык: `self-improve` (загружать при запуске цикла). Расписание OpenChamber: «Самоулучшение Домового» (агент `domovoy`, cron `0 */4 * * *`, `Europe/Moscow`).
- Разрешённая область: `homelab/`, `agentos/`, навыки, docs/reports. Запрещено: изменения роутера/HA/firewall/устройств, секреты, установка пакетов, разрушительные действия.
- После успешного улучшения: `python3 homelab.py backup` (+ по возможности `android-device file-backup`) и запись в changelog/state.

## AgentOS (113 офлайн мини-агентов)

Детерминированная мультиагентная система на stdlib, без LLM и сети:
`/root/workspace/agentos`. Точка входа — `agentos` (wrapper в
`/usr/local/bin/agentos`) или `./bin/agentos` из каталога проекта.

```bash
agentos selftest                 # 113 агентов + 50 маршрутов, «ВСЁ РАБОТАЕТ»
agentos "покажи arp таблицу"     # маршрутизация по смыслу
agentos list                     # все агенты
agentos run <id> "аргументы" --live   # конкретный агент; без --live — dry-run
agentos serve --open                  # браузерный UI на 127.0.0.1:8765
python3 -m unittest discover -s tests # 52 теста
```

- Память и конфиг: `agentos/data/`, результаты: `agentos/out/`.
- Документация: `README.md`, `RUNBOOK.md`, `CATALOG.md` (обновлять:
  `agentos catalog`).
- Агенты `net.*`, `hl.*`, `sec.*` используют `../homelab/homelab.py`.
- Секреты не читаются и не логируются; изменяющие действия только с `--live`.
- Переносимый комплект: `python3 tools/build_portable.py` →
  `dist/agentos-portable/` (+ zip), запуск `./start.sh` / `start.cmd` (браузер), `start-lan.cmd` — LAN;
  на Windows Python 3.12 уже внутри;
  данные рядом с папкой.
- LLM опциональна: `ai.*` включаются сами, если поднят локальный
  OpenAI-совместимый сервер на 127.0.0.1:8080/11434.
