# Changelog

## 1.4.1 / 1.3.1 — 2026-11-21 (QR-привязка)

* Консоль показывает крупный QR со всей строкой привязки `hg1:…` — ребёнок
  наводит камеру агента, код подставляется сам. Ручной ввод оставлен запасным.
* Агент: новый экран сканирования (`ScanActivity`, Camera2, без внешних
  библиотек) с разрешением `CAMERA`; кнопка «Сканировать QR» в карточке
  привязки, подсказка держать экран ровно.
* Свой QR-кодек на чистом Java (версия 5, уровень L, маска 0): энкодер
  проверен стандартным декодером OpenCV, камерный декодер — хостовыми тестами
  на прямом кадре. Никаких зависимостей, офлайн.
* Протокол HMAC не менялся: совместимость с парой 1.4.0 / 1.3.0 сохранена.
* Подпись APK тем же ключом; `versionCode` консоли 7, агента 6.

## 1.4.0 — 2026-11-17 (безопасность)

* Консоль подписывает ответы: `RESP|path|ts|nonce|sha256(body)`. Агент
  проверяет подпись, окно ±300 с и повтор nonce до разбора JSON — политика и
  команды из неподписанного ответа игнорируются. Закрыт путь «подменённый
  сервер → `wipe`».
* Привязка только к приватным IPv4 (10/8, 172.16/12, 192.168/16, 127/8,
  169.254/16) с подтверждением адреса консоли на экране агента.
* Сервер закрывает соединения с публичных адресов, ограничивает тело (64 КБ),
  заголовки (32 шт / 16 КБ), строку (4 КБ) и весь запрос (15 с).
* Nonce: 16–64 hex, TTL 10 мин, кэш ≤ 10 000; `ack` привязан к устройству,
  ID команды — 128 бит; короткое тело запроса — ошибка.
* Валидация экранного времени 0…1440 мин, `LIMIT` в SQL параметризован.
* R8 + `shrinkResources` в релизах: 97 КБ консоль, 73 КБ агент.
* `FLAG_SECURE` на экране кода привязки, усечение текста SOS (200 символов).
* `docs/SECURITY.md`: модель угроз, закрытые пункты, остаточные риски.
* Автотесты: 34 проверки, включая подпись ответов и nonce консоли.


## Агент 1.3.0 — 2026-11-17 (безопасность)

* Проверка подписи ответа консоли перед применением политики и команд,
  с защитой от повтора ответа (кэш nonce на 512 записей).
* Код привязки принимается только с приватным IPv4-адресом; перед сохранением
  показывается диалог «Привязать к этой консоли?» с адресом и ID.
* Версия агента поднимается вместе с консолью: протокол несовместим со старой
  парой (1.3.0 консоль ↔ 1.2.0 агент), обновляйте оба APK.


## Агент 1.2.0 — 2026-11-17 (экран защиты и мастер настройки)

* Новый экран агента в том же стиле, что консоль: градиентная шапка,
  «стеклянная» карточка со статусом, прогресс готовности, последняя
  синхронизация и версия политики.
* SOS — крупная кнопка сразу под шапкой: сигнал и координаты уходят в консоль
  одним нажатием; кнопка есть и на экране блокировки.
* Чек-лист настройки вместо девяти кнопок: права владельца, привязка,
  уведомления, геолокация, статистика использования, спец. возможности,
  overlay, батарея, ADB. У каждого пункта — состояние и действие, так что
  чек-лист работает как мастер первого запуска.
* Экран тихого часа перерисован: тёмный градиент, крупные часы, понятная
  причина блокировки, SOS; блокировка задачи и опрос состояния сохранены.
* Диагностика вынесена в отдельную карточку, версия читается из пакета.
* Защита стартует сама при открытии агента (watchdog + синхронизация +
  планировщик), отдельная кнопка «Запустить защиту» больше не нужна.
* Дизайн-система `Ui.java` живёт внутри агента: framework-виджеты, 21
  векторная иконка, без AndroidX. APK 94 КБ.


## 1.3.0 — 2026-11-17 (надёжность данных)

* Миграции базы: `Db.DB_VERSION = 2`, `onUpgrade` больше не пустой — обновление
  приложения не ломает данные.
* События дедуплицируются: повторная доставка после потери ack не создаёт дублей.
* Ретенция: события 120 дней, статистика 400 дней, завершённые команды 30 дней,
  запускается раз в сутки.
* Зашифрованная резервная копия: PBKDF2-SHA256 (150k) + AES-256-GCM, файл
  `.hgbak` в «Загрузки/HomeGuard», восстановление через системный выбор файла.
* Локальный лог сбоев (`files/crash.log`, 64 КБ) и просмотр из настроек.
* Автотесты протокола без JUnit и сети: `sh tools/test.sh` — 29 проверок,
  включая вектор HMAC RFC 4231 и совместимость агент ↔ консоль.
* Экран «Данные» в настройках: копия, восстановление, лог сбоев, очистка истории.
* Документация: `docs/OPERATIONS.md` (бэкап, восстановление, обновление, диагностика).


## 1.2.0 — 2026-11-17 (консоль)

* Новый интерфейс: светлая тема, градиентные шапки, карточки со скруглением 20dp,
  нижняя навигация из четырёх вкладок.
* Главная: суммарное экранное время за день, статус сервера, карточки детей
  с прогрессом дневного лимита и батареей.
* События: лента по дням, иконки по типу (SOS, блокировка, приложение, правила),
  расшифровка причин.
* Отчёты: график экранного времени за 7 дней, топ приложений с прогрессом,
  фильтр по ребёнку.
* Настройки: адрес сервера, все интерфейсы, копирование адреса, проверка сервера,
  список детей, сведения о приложении.
* Экран ребёнка: hero-карточка, кольцо экранного времени, быстрые действия,
  опасные действия вынесены в отдельный блок с подтверждением.
* Правила: сгруппированы по смыслу (время, приложения, устройство, защита, киоск).
* Мастер «Новый ребёнок» с готовым кодом привязки и инструкцией.
* 21 векторная иконка нарисована вручную, без библиотек: APK 108 КБ.


## 1.1.1 — 2026-11-17

* Смена сети (Wi-Fi → мобильный → VPN и обратно) больше не съедает паузу
  повторов: при появлении/смене сети синхронизация запускается сразу,
  backoff ограничен 4 минутами вместо 10.
* `isHomeNetwork()` корректно определяет Wi-Fi и при постоянно включённом
  VPN (смотрит все сети, а не только активную).
* Очередь событий по-прежнему не теряется: неотправленное досылается при
  первом же успешном синке.


## 1.1.0 — 2026-11-16

* Привязка по нескольким адресам: `hg1:LAN+WG:порт:ID:КОД`. Агент запоминает
  рабочий адрес и автоматически переключается между LAN и WireGuard.
* Консоль показывает все свои IPv4-адреса (Wi-Fi, Ethernet, туннель).
* В экране «Новый ребёнок» появилось поле для адреса в WireGuard.
* Исправлено: события (включая SOS) не теряются при обрыве связи — удаляются
  только после подтверждения синхронизации консолью.
* Иконка приложения, локаль в разборе HTTP-заголовков, запуск анимации оверлея.


## 1.0.0 — 2026-11-16

Первый рабочий выпуск.

* **Агент** (`ru.homeguard.agent`): Device Owner DPC, foreground-синхронизация
  (60/120 с), применение политик, блокировка приложений, установок, камеры,
  Wi-Fi/BT/USB, скриншотов, статус-бара, keyguard, safe boot, factory reset,
  отладки; киоск-режим; расписание и дневной лимит; overlay-блокировка;
  разовый запрос геопозиции; SOS; watchdog-джоба; экспорт статистики
  использования.
* **Консоль** (`ru.homeguard.console`): встроенный HTTP-сервер на 8787,
  HMAC-аутентификация с nonce и окном ±300 с, SQLite (устройства, политики,
  команды, события, usage), экраны устройства/политики/отчётов, привязка
  одним кодом, уведомление об SOS.
* Протокол `hg1`, подпись проверена независимой реализацией на Python.
* Сборка на arm64: aapt2 через qemu, документация в `docs/BUILD.md`.
* Известные ограничения перечислены в `README.md`.
