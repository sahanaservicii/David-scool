# Эксплуатация HomeGuard

Короткие процедуры для повседневного использования. Всё локально: ни облака,
ни аккаунтов.

## Где лежат данные

| Что | Где |
|---|---|
| Дети, правила, события, статистика | SQLite `homeguard.db` во внутреннем каталоге консоли |
| Секреты привязки | там же, зашифрованы ключом Android Keystore (AES-256-GCM) |
| Лог сбоев консоли | `files/crash.log` (до 64 КБ, старое уходит в `.1`) |
| Резервные копии | «Загрузки/HomeGuard/homeguard-YYYYMMDD-HHmm.hgbak» |

Сроки хранения (ретенция, раз в сутки при старте приложения):

* события — 120 дней;
* статистика по приложениям — 400 дней;
* завершённые команды — 30 дней.

## Резервная копия

1. Консоль → **Настройки → Данные → Резервная копия**.
2. Придумайте пароль (минимум 6 символов). Он **не хранится**: без него файл
   не открыть.
3. Файл появится в «Загрузки/HomeGuard».

Внутри: дети (включая коды привязки), их правила, 30 дней событий и 60 дней
статистики. Шифрование: PBKDF2-SHA256 (150 000 итераций) + AES-256-GCM.

Копия переносится на новый телефон обычным файлом (кабель, флешка, локальный
обмен). Облако не нужно.

## Восстановление

1. Установите консоль на новый телефон, откройте.
2. **Настройки → Данные → Восстановить из копии**, выберите файл `.hgbak`,
   введите пароль.
3. Записи с теми же `id` заменяются, остальные дети не трогаются. Старые
   события не удаляются.

После восстановления агент на телефоне ребёнка продолжает работать: `id` и код
привязки те же.

Важно: на новом телефоне консоли адрес сервера другой (например,
`192.168.1.23` вместо `192.168.1.5`). Агент переключается сам только между
двумя адресами из строки привязки. Если LAN-адрес изменился, откройте экран
ребёнка → «Код привязки» и введите новую строку в агенте — или закрепите адрес
DHCP-лейзом на роутере (см. `PROVISIONING.md`).

## Лог сбоев

**Настройки → Данные → Лог сбоев**: последние 64 КБ, кнопка «Копировать».
Пишется только при падении приложения, никаких сетевых отправок.

## Обновление APK

1. Соберите релиз: `sh tools/build.sh` (см. `BUILD.md`).
2. Проверьте: `sha256sum -c dist/SHA256SUMS`, `sh tools/test.sh`.
3. Установите `console-<версия>.apk` поверх старой — база мигрирует сама
   (`Db.DB_VERSION`), данные сохраняются.
4. Агент обновляется отдельно, тем же способом; Device Owner сохраняется.

Откат на предыдущую версию APK возможен только установкой более нового
`versionCode`. Если нужно откатиться по данным — восстановите резервную копию.

## Диагностика

| Симптом | Что проверить |
|---|---|
| «сервер выключен» в консоли | Настройки → «Проверить»; уведомление консоли; разрешение на уведомления |
| ребёнок «офлайн» | один Wi-Fi или живой WireGuard-туннель; `ping 192.168.9.2` с телефона ребёнка |
| события не появляются | на телефоне ребёнка: доступ к статистике использования, отключённое энергосбережение |
| команда «в очереди» дольше 5 минут | телефон ребёнка офлайн; команда уйдёт при следующей синхронизации |
| консоль падала | Настройки → Лог сбоев |

## Что не делать

* Не открывать порт 8787 наружу и не включать UPnP/DMZ.
* Не включать ADB по TCP на телефоне ребёнка.
* Не хранить пароль от резервной копии в переписке и заметках.
